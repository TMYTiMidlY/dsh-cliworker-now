# Spec Delta

## ADDED Requirements

### Requirement: Cursor准备期元数据故障诊断
Cursor账号与任务准备查询发生元数据子进程失败时，系统 SHALL 提供有界的入口解析（resolve）、启动、读流、退出或超时阶段及可确认的安全退出/系统原因；未知进程失败 MUST 不被描述为已登出、额度耗尽或账号切换。诊断 MUST 不包含原始异常、stdout/stderr、环境、凭据、账号标识或argv。该诊断不得授权任务或替代原生身份核验。

#### Scenario: 捕获前入口解析失败
- **WHEN** Cursor binding 在元数据捕获前的 resolver 同步或异步失败
- **THEN** 只映射为安全 resolve 阶段，不复制路径/原异常，不更改入口选择或账号判断；已取消请求零 resolve/零 spawn，typed 清理未确认优先

#### Scenario: 原生身份命令退出失败
- **WHEN** Cursor原生身份元数据进程已确认退出但返回不可接受的退出结果
- **THEN** 返回退出阶段与已验证退出码或未知原因；不发送prompt，不修改账号/模型/历史，不把该退出码当认证拒绝

#### Scenario: 矛盾或畸形的完成证据
- **WHEN** Cursor安全元数据调用报告允许的退出码，但同时含任意非null且非undefined的signal，或退出码并非有效uint32
- **THEN** 不接受成功，返回安全exit阶段及固定signal/unknown原因，不复制原signal，也不据该数据推断认证失效

#### Scenario: 非Cursor默认分支的取消竞态
- **WHEN** 未启用安全诊断的既有调用在spawn或读流原错误发生时同时收到调用者取消
- **THEN** 保留既有原错误身份及清理行为，不将本次Cursor诊断的取消覆盖规则扩展到其他CLI

#### Scenario: 启动或读流失败
- **WHEN** 身份元数据进程无法启动或流读取失败
- **THEN** 显示对应阶段及允许列表内的系统原因；未知异常只给固定未知标签，原始内容不进入公开错误或日志

#### Scenario: 查询超时或用户取消
- **WHEN** 查询自己的有界期限到达或调用者主动取消
- **THEN** 分别保留超时与取消事实，并等待原进程范围清理；取消不自动变成登录失败，也不生成第二次查询或任务

#### Scenario: 清理无法确认
- **WHEN** 任一元数据失败后无法确认进程范围已退出
- **THEN** 仍以清理未确认为优先并保留既有CLI范围保护，不用阶段诊断覆盖或释放准入

#### Scenario: 独立状态与目录成功
- **WHEN** 准备查询失败，但另一次原生账号或目录查询已经成功
- **THEN** 分别呈现各自证据，不用成功目录掩盖准备失败，也不据准备故障宣称旧登录失效；只有后续新的合法核验才能重新尝试

#### Scenario: 私密失败载荷
- **WHEN** 不可接受进程输出或异常含token、邮箱、endpoint、配置路径、argv或任意marker
- **THEN** 公开结果只包含固定阶段、经验证数值与允许的原因标签，不复制、截断展示或散列输出该私密载荷
