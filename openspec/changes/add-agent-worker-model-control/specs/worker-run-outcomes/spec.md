# Spec Delta

## ADDED Requirements

### Requirement: 主 Agent 按运行身份读取公开回复
系统 SHALL 提供父会话范围内的只读结果工具，以 Worker ID 或精确名称和可选 runId 查询公开正文及运行状态；指定 runId 不存在时 MUST 明确返回不存在，不能回退到最新或历史 lastResult。长正文 SHALL 有界分页并说明后续游标，禁止静默截断。

#### Scenario: 后续轮已经开始
- **WHEN** Worker 已进入第二轮，但调用方读取第一轮的 runId
- **THEN** 只返回第一轮公开正文、状态和可核查身份，不用当前模型或当前结果覆盖第一轮。

#### Scenario: 长回复与重复读取
- **WHEN** 同一轮回复超过单次读取预算，调用方按返回游标继续读取
- **THEN** 可以按顺序重建完整公开正文；相同快照/游标重复读取稳定，不产生重复模型执行或丢失文本。

#### Scenario: 归属不符或历史缺失
- **WHEN** Worker 不属于当前父会话，或指定运行没有足够保存证据
- **THEN** 拒绝跨会话读取或明确说明缺失，不读取其他会话、凭据或原始私密载荷补充。

### Requirement: 结果回执区分模型配置与原生证据
结果回执 SHALL 分开提供运行身份、该轮配置模型、该轮观察到的模型、正文和最终状态；尚无原生模型证据时 MUST 明示未知，不能用正文自称、Worker 当前偏好或另一轮的模型填充。

#### Scenario: 已改模型但还未执行
- **WHEN** AGY Worker 已从 Argon 配置成 Opus，但尚未取得 Opus 运行证据
- **THEN** 不将配置回执描述为 Opus 已执行，也不改写旧轮的 Argon 身份。

#### Scenario: 原生模型与预期不一致
- **WHEN** 原生初始化报告的模型不等于本轮明确选型
- **THEN** 保留真实模型冲突并拒绝成功声明，不能把该回复计作预期模型完成。

### Requirement: 失败回复与部分执行可取回
结果工具 SHALL 保留失败、中断和结果待核实轮次中已经公开的回复，并独立标注错误、完整性及清理状态；读取和分页 MUST 不改变原终态、不自动续聊或重试。

#### Scenario: 流中断已有多段正文
- **WHEN** 同一运行已有多段公开回复，但最终因 stream interrupted 失败
- **THEN** 按原始顺序保留可取回的正文，仍报告失败或待核实，不把同一次运行的片段算作新的审阅阶段。

#### Scenario: 本轮没有正文
- **WHEN** 目标轮只发生启动或超时错误，没有公开回复
- **THEN** 返回空正文和该轮错误，不借用该 Worker 以前成功轮次的答案。
